# Independent Projects → Graham Friedman

This repository contains self-directed work built outside any coursework: original analysis, frameworks, and systems spanning data analysis, decision modeling, and applied AI. The focus is on analytical judgment and structured problem-solving, turning complex, high-stakes questions into clear, defensible, decision-relevant recommendations.

## Featured Projects

### The Platform Selection Engine
An original, weighted, dollar-based decision framework for high-stakes platform and vendor selection. It resolves every capability and every external cost into a bounded dollar figure, separates the sticker-price question from the true total-cost question, and carries the decision through to an executive readout. Methods include total-cost-of-ownership modeling, PERT three-point estimation, AHP criteria weighting, Monte Carlo simulation, and sensitivity analysis. Two worked domains (a data-warehouse / ML-platform selection and a CRM selection) illustrate the method, which is domain-agnostic.

View Project → [platform-selection-engine](https://github.com/grahamdfriedman12/graham-friedman-independent-projects/tree/main/platform-selection-engine)

### Automate the Intake. Preserve the Thinking.
A 23-page philosophy paper on AI deployment and human judgment, paired with an 18-slide work showcase presented live to a consulting firm's AI team. Covers the Automate, Amplify, Preserve framework, context architecture design, and broader commentary on how organizations should think about deploying AI. The paper is the philosophy. The presentation is the applied system.

View Project → [automate-the-intake](https://github.com/grahamdfriedman12/graham-friedman-independent-projects/tree/main/automate-the-intake)
